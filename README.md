📌 Project Overview

This project focuses on analyzing retail sales performance and uncovering meaningful business insights using Microsoft Excel, SQL, and Power BI.

The analysis follows an end-to-end data analytics workflow, including data cleaning, exploratory analysis, SQL-based business analysis, and interactive dashboard development. The project evaluates sales and profitability across multiple business dimensions such as regions, product categories, customer segments, states, and products.

🎯 Project Objectives

The key objectives of this project are:

Clean and prepare raw retail sales data for analysis.
Perform exploratory data analysis using Microsoft Excel.
Analyze business performance using SQL queries.
Identify sales and profitability trends across different dimensions.
Evaluate regional, category, segment, state, and product performance.
Develop an interactive Power BI dashboard for KPI monitoring.
Generate actionable business insights and recommendations.

💡 Key Business Insights

The analysis revealed meaningful variations in business performance across different dimensions.

Some of the key insights include:

Sales and profitability vary significantly across regions.
Certain product categories generate high sales but comparatively lower profitability.
Customer segments demonstrate different purchasing patterns.
Specific states contribute significantly to overall revenue.
Top-performing products drive a substantial portion of total sales.
Some products and regions require strategic attention due to lower profitability.
