# 📊 Financial Performance Analysis

## 📌 Project Overview

This project focuses on analyzing retail sales performance and uncovering meaningful business insights using **Microsoft Excel, SQL, and Power BI**.

The project follows an end-to-end data analytics workflow, including **data cleaning, exploratory data analysis, SQL-based business analysis, and interactive dashboard development**. The analysis evaluates sales and profitability across multiple business dimensions such as regions, product categories, customer segments, states, and products.

---

## 🎯 Project Objectives

- Clean and prepare raw retail sales data for analysis.
- Perform exploratory data analysis using Microsoft Excel.
- Analyze business performance using SQL.
- Identify important sales and profitability trends.
- Evaluate regional, category, segment, state, and product performance.
- Develop an interactive Power BI dashboard for KPI monitoring.
- Generate meaningful business insights and recommendations.
